eBPF-Based Study of Linux CPU Scheduling Fairness
Project Overview
This project studies Linux CPU scheduling fairness under mixed interactive and batch workloads using eBPF-based scheduler tracing.
Objectives
* Observe Linux scheduler behaviour.
* Measure runnable wait times and workload performance.
* Compare scheduling policies.
* Evaluate fairness and interactive responsiveness.
Project Structure
* workloads: Workload generators
* telemetry: Scheduler tracing
* policies: Scheduling policies
* experiment: Experiment execution
* analysis: Metrics and plots
* configs: Experiment configurations
* results: Experimental output
* docs: Documentation
* paper: Final report
